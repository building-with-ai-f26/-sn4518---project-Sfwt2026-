# FlexWeek exercise catalog: which wger exercise each of ours matches.
# wger (https://wger.de) is the free exercise database the app fetches descriptions from.
# One line per catalog exercise, four columns separated by " | ":
#
#   catalog id | wger id | wger name | note
#
# wger id = the number of the matching wger exercise, or "-" for no match.
#   The app then shows our own catalog instructions for that exercise.
# wger name and note are for people reading this file; the build ignores them.
#
# A match is only set when both are true:
#   1. Same exercise: same movement, same equipment, same variation.
#   2. wger's English text explains the movement in at least about 100 characters
#      (not empty, not a one-line note or link, not only a list of benefits or muscles).
# Reviewed by hand on 2026-11-16 against wger's 973 English exercises.
#
# To check or change a line:  node scripts/wger-lookup.js find <text>   /   node scripts/wger-lookup.js show <wger id>
# After editing, rebuild the catalog:  node scripts/build-catalog.js
